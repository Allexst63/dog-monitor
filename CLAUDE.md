## Как не тратить токены
- **Не читать index.html целиком** (~8,5 тыс. строк, 660 КБ). Сначала `docs/MAP.md` — разделы и функции со строками
  (пересобрать: `python3 tools/map.py`), потом только нужный кусок: `sed -n 'A,Bp' index.html` или `grep -n`.
- README.md длинный (история версий) — читать по `grep -n`, не целиком.
- Логи GitHub Actions — `tail_lines` 40–90, список запусков — `perPage` 5–10.
- Проверка после правок: `node tools/selfcheck.js . /tmp/sc.json | grep -v ^OK` (≈2 мин, 67+ пунктов; живые соединения
  бирж из песочницы недоступны — эти пункты пропускаются, в GitHub Actions обязательны).

## Устройство
- Страница — один `index.html` (разметка + CSS + JS в одном файле, без сборки). `classic/` — старая версия, не трогать.
- Данные — `data/*.json`, их 4 раза в день собирает `daily.yml` (python: `tools/daily.py`, `dogmon.py`, `fetch.py` …),
  перед выкладкой страница проверяется в браузере (`tools/selfcheck.js` → `data/selfcheck.json`).
- `fng.yml` — каждый час: свежие «страх и жадность» (CoinMarketCap браузеру не отвечает — только с сервера) и сторож:
  сводка старше 7 ч → сам запускает `daily.yml` (cron GitHub опаздывает на часы и пропускает запуски).
- `sitecheck.yml` — живой сайт каждые 2 ч (повтор через минуту, письмо — только если не прошло дважды).
- `alert.yml` — сигнал о резком движении цены.
- Закрытая часть (план, не включена): приватный `dog-monitor/engine` (src/index.html, tools/mood.py) — см. README.

## Правила, которые легко сломать
- **Одна цена на весь сайт**: середина лучших заявок Kraken DOG/USD и Gate DOG/USDT — **бо́льшая из двух** (`liveMid`,
  `obPx`, без живой — `pxRep` по стаканам сводки). «Главное» и стакан «All exchanges» показывают одно число; сводный стакан
  режется по нему (покупки ниже, продажи выше). Решение владельца 21.11.2026.
- Стакан перерисовывается «морфом» (`morph`/`mNode`): строки по `data-ob`, числа с `data-v` крутятся барабаном
  (`rollSet`). Не возвращать `innerHTML` для `#obcard` — пропадёт плавность.
- Масштаб страницы выключен (viewport + `touch-action: pan-x pan-y` + gesture*), графики масштабируются сами.
- Графики: справа запас (`hGap`), тянуть вправо можно до ~30% ширины (`rClamp`).
- Лист снизу закрывается, если смахнуть вниз из любого места (когда он прокручен к началу) — `sheetDrag`.
- Новый пункт — новая проверка в `tools/selfcheck.js`; запись в README (раздел версии).
- Коммиты — по-русски, кратко, что изменилось для читателя.
